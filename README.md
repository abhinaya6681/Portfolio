# CHILUKA ABHINAYA — Portfolio

Dark black / silver / ash portfolio inspired by the structure and feel of the supplied reference portfolio.

## Files
- index.html
- style.css
- script.js
- assets/profile.png
- assets/CHILUKA-ABHINAYA-Resume.pdf

## GitHub Pages
1. Open your `abhinaya6681/Portfolio` repository.
2. Replace the existing website files with these files, preserving the `assets` folder.
3. Commit changes to `main`.
4. In Settings → Pages, use `Deploy from a branch`, branch `main`, folder `/ (root)`.
5. Open `https://abhinaya6681.github.io/Portfolio/`.

The website uses only HTML, CSS and JavaScript, so no build step is required.
