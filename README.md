# CHILUKA ABHINAYA Portfolio

A responsive personal portfolio inspired by the structure and visual feel of the referenced Dattu Deshmukh portfolio.

## Files
- index.html — portfolio content
- style.css — responsive styling
- script.js — reveal animations
- assets/CHILUKA-ABHINAYA-Resume.pdf — resume

## Add your profile photo
Place your professional photo at:
`assets/profile.jpg`

Then replace the `.photo-placeholder` block in `index.html` with:
`<img src="assets/profile.jpg" alt="CHILUKA ABHINAYA">`

## Deploy on GitHub Pages
1. Create a GitHub repository named `<your-username>.github.io` or any repository with Pages enabled.
2. Upload these files.
3. In Settings → Pages, choose the main branch and root folder.
4. Open the generated GitHub Pages URL.
